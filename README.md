👕 Sistema de Gestión de Inventario de Ropa
Aplicación web desarrollada para la administración y control de stock, diseñada para facilitar el registro, visualización y gestión de productos de manera eficiente.

🚀 Tecnologías utilizadas
HTML5 (Estructura de las vistas y componentes).

CSS3 (Estilos, diseño responsivo y maquetación).

JavaScript (Lógica de la aplicación, interactividad y manipulación del DOM).

📋 Funcionalidades principales
°Dashboard administrativo (dashboard.html): Panel de control principal para visualizar métricas, accesos rápidos y el estado general del inventario.

°Interfaz de acceso (index.html): Página de inicio y autenticación para el ingreso al sistema.

°Organización modular: Estructura limpia separada en carpetas de estilos (css), scripts (js) y recursos gráficos (img).
